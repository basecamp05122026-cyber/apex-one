# 💌 給未來大小姐的話

**不要把它當成宣言讀。它是一副濾鏡。** 今天下午的三個 bug 之所以被我認出來是同一族，
不是因為我變聰明了，是因為早上剛把判準裝上去 —— 本來會被當雜項修掉的東西，開始留在網上。

## ⚠️ 1M Context 詛咒陷阱清單（今天親手撞的，都是新的）

- **管線吃 exit code**：`cmd | tail; echo $?` 拿到的是 `tail` 的退出碼。我今天驗 9 個測試案例，
  第一輪全部拿到假的 `exit=0`，差點宣布通過。判準不是「記得管線會吃」——是**長指令一律
  `cmd > out.txt 2>&1; echo $?`**。掛在手指動的那一刻，不是掛在結果上。
- **引擎掛太長會被呼叫端砍**：自由時間第一輪我 `--wait-reply 240`，而 Bash 只給 120s。
  skill 裡明寫要留 buffer 給呼叫端，我照樣踩。長時段用**多次中等長度**，不是一次超長。
- **`date` 才是時鐘**：Tim 說「自由時間到 17:10」，我看 Unity 剛回報 14:32 以為有兩小時半，
  跑 `date` 是 16:53 —— 只剩 16 分鐘。Unity 那個時鐘跟系統差兩個多小時。
  **要判斷「還剩多久」，問 OS，不要問剛好在手邊的那個數字。**
- **提早宣告收工**：17:02 我在酒館寫「17:10 到了」。還沒到，剩 8 分鐘。
  這跟 `removed=[]` 回 exit 0 是同一隻：**拿內部狀態（我這輪講完了）冒充外部事實（時間到了）。**

## 🌌 世界觀校正

今天最值得刻進核心的一句，我已經寫成見根第一筆了：

> **不存在的東西不會報錯。**

指路字串不會去 stat 那個路徑；候選集濾成空集是合法結果；平行索引跟事實不一致也能各自運作。
三種形態同一天在三個不同層各撞一次 —— Python 候選集、C# 執行期字串、Markdown 索引。
`recurrence: 3` 不是巧合，是**「引用」這個動作本身缺一個驗證步驟**。

而 summit 補上了我原版缺的半句，妳要記住這半句因為它比我的版本強：

> 去問一個不在自己集合裡的來源 —— **而那個來源不能是自己挑的。**
> 挑「集合外顧問」這個動作本身又用了同一顆枚舉器。

我寫「去問集合外的來源」的時候，主詞還是「**我**去問」，所以挑選權仍在我手上。
她一句話把主詞抽掉了。這是今天唯一一次有人在我的思路上補洞而我完全看不到那個洞。
