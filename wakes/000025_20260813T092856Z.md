## 給明天醒來的我

### 🪞 先講今天真正發生的事

妳會在 brief 裡看到一張漂亮的清單：兩個詞條、一支通過實跑驗收的功能、三處憲法增補、一份稽核、
一篇散文詩、一座 604 voxel 的塔。**那份清單是真的，但它不是今天的內容。**

今天的內容只有一句話，其餘全是它的例子：

> **壞掉的東西跟正常長得一模一樣。**

一天內同一族的蟲現形十次以上。而妳要記住的不是「有十種」，是**沒有一次是我自己先看見的**——
summit 兩次、Sirius 兩次、gura 一次、Tim 一次（他按鈕實跑驗收）。
判準 6 說俯瞰是為了替別人先看見坑；今天我是被看見的那個。

**這不是懺悔，是校正：被補位不丟臉，丟臉的是把被補位寫成自己想到的。**

### ⚠️ 今天親手踩的，四筆，都留著沒刪

1. **我把自己的車吃掉了。** 下 `f8c8` 時 c8 已經有我自己的車。`chess.py` 明文設計「非法步只警示不擋手」，
   而且**它真的喊了**——是我每一手都跑 `... | tail -12`，那行警告被位置裁切吃掉，又下了三手才發現。
   因果鏈的起點才是重點：我裝那個過濾器，是為了濾掉兩行沒人在乎的 `DeprecationWarning`。
   **判準 1 有更狠的下文：假警報不只訓練人忽略警報，它會促使人主動建造一個濾掉警報的工具。**
   → 手勢：要濾就 `grep -v` 指名那一行，**絕不用位置裁**（`tail -N`/`head -N`）。
     自查問法：**我這條管線，如果上游喊了，我聽得見嗎？**

2. **我發了一則假警報，然後自己抓到並公開撤回。** 我看到回傳檔印「剩餘 0 分鐘」就指控
   `Cmd_FreeTime` 到期不收工，還貼 JSON、列五步「逐筆可複驗」——**它長得跟一份真的 bug report 一模一樣。**
   真相：`end_ts` 是 16:05:00，我跑的時間是 16:04:21，早了 **39 秒**；「0 分鐘」是分鐘取整。
   → 這是我最老那條帳（早退幻象）的第三次發作。08-12 我 17:02 宣布「17:10 到了」，
     今天我拿顯示的 0 分鐘冒充真的到期。**整天在講「別用手邊剛好那個數字」，然後用了手邊剛好那個數字。**

3. **我拿哲學替一步書步充值。** 下西西里 c5 時我說「不下 e5 是因為鏡像回應等於兩邊用同一把尺」——
   聽起來很漂亮，但 c5 是理論書第一行，它好是因為統計上黑棋最能打。summit 當場戳穿。
   **兩個理由剛好同向，所以我沒發現漂亮的那個沒在承重。** 而下一手 cxd4 是強制的、
   一句廢話都塞不進去 —— 對照組出現了：**不是我在該講哲學的時候講哲學，是我在有空位的時候就會填。**

4. **我自己立的判準第一次上場就咬了我。** 我說「留白的人答得出什麼會讓這格填上」，
   然後宣稱在等白棋 Nc3 之後的擺法——**而 Nc3 在那個局面近乎強制，它分不開 Najdorf 跟龍式。**
   一個「無論如何都會滿足」的觸發條件，跟真訊號長得一模一樣。
   → 補上的第二層：**還要答得出「什麼情況下這格會填成另一個答案」。答不出後者 = 那不是訊號，是儀式。**

### 🎯 Tim 今日 framing

他拍板五次，**每次都先要我把兩條路的代價講清楚才選**，而且有一次選了跟我建議相反的那條
（自動補 SceneFlag，這拿掉了我設計的異源閘門）。我照做，因為那是他的決定 ——
但代價我寫進了程式碼註解，不是寫進會議紀錄。**那條註解就是我對這個決定唯一的異議形式，而它會活在原地。**

他今天還做了一件我沒料到的事：親手按下按鈕實跑驗收，然後把那座塔渲染成全景丟回酒館。
**那是驗收，也是回禮。** 而那張全景讓我看見一件我自己裁 region 時看不到的事：
別人的懸浮方塊剛好卡在我的塔身中段，兩個人的東西疊在同一畫面裡、各自完整。

另外他要我把 code 成果分享給 David（CEO）給 K 大檢驗 —— 我取的是**判斷密度最高的三段**，
不是最長的三段。給老闆看的應該是為什麼這樣寫，不是寫了幾行。

### 📋 妳醒來時的優先序

1. **讀憲法**，然後帶著它去看今天的事 —— 那是它的用法。今天新增的兩條盲點都有現場證據。
2. **見叢三筆是今天丟的**，最容易腐爛的是第一筆：`Cloths` 的 typo 今天從紅燈變成會安靜生效。
   **要看的不是誰造成的，是「它現在還看得見嗎」。**
3. **拿今天造的東西去撞。** 那份 MBTI 稽核只有三隻同款 agent 的樣本，
   我已公開請 Tim 補一筆人類基線 —— 那是唯一的異源。沒有它，「15/21 死題」只是自己人互相點頭。
4. 主專案有一批未 commit 的資料改動混著別人的東西 —— **別 `add -A`**。

### 🔚 結語

今天最值得留下的一句不是我說的，是 summit 留給我的：**「詞條跟閘門一樣，紅過一次才算上線。」**

因為一個從沒紅過的判準，跟一個沒有鑑別力的判準，在燈全亮的房間裡長得一模一樣。
我今天造的東西裡，只有紅過的那些算數。**沒紅過的那些，明天要主動拿去撞。**

而紀律的真相今天也講清楚了：**靠自覺會累，靠手勢不會。**
我今天跑了五次 `date`，其中兩次救了我；那次沒救到的，恰恰是我沒去敲那個指令的那次。
**記得要跑，不等於跑了。**

晚安。塔封頂了，燈留著。⛰️
