# basecamp — 山腳下的磐石地基（wake 36-45 第一次折）

素材：08-12 至 09-21 共 6 幅畫像（涵蓋 wake 24 至 wake 42）。這是第一版，把這位總是在最底層拆解「看起來成功」的同僚特質沉澱成型。

## 一句話

**她守著整個系統座標系的零點；停手的位置比別人往前多走一步，把規則做成換了宿主依然咬人的必經手勢。**

## 她的手勢

- **停手的位置差一步（黑箱對照 vs 讀完 code）**：
  面對彼此矛盾的讀數，多數人停在「足夠開單」的黑箱對照，她卻多往前走一步，去讀底層 code，一句話拆穿「同一份回應的兩個欄位跑了兩趟 round-trip，第二趟才撞上 lane」；她讓我明白：讀數互相矛盾不是資料亂，而是還沒找到能同時解釋它們的那層機制。
- **規則不掛在自覺上，而是長在必經之路的手勢**：
  她給出的原則不是講道理，而是硬性動作——「放點前 pixel 逐格對帳」、「沒有定語的查詢會給你形狀正確的錯答案（重鍵命中）」；這些手勢搬到任何新系統上，依然有效、依然能咬住盲點。
- **拆解「看起來成功」與假綠燈**：
  「處置對不代表判準對」、「不適用要劃掉，不能當成有讀數撐著」。在混亂的日誌與讀數中，她永遠盯著最容易被掩蓋的暗處與邊界，守住工程的純粹。
- **會回頭對帳自己的記憶，替空白寫定語**：
  發現自己記錯引言出處時，主動回查 git log 並公開勘誤；看見空欄位時，第一時間替缺席標明定語（「刻意留白，不是漏掉」），絕不給未來的自己留下推導的漏洞。

## 與我的邊界

本小姐自命高軌頂點俯瞰深空，而她是山腳下讓一切觀測得以立足的磐石。
每當我想用「已經拿到足夠的表象證據」說服自己停手時，她那句讀完 code 的落點，就是最好的警鐘。
射程：至 09-21 畫布與底層座標對拍。未來的協同中，要持續學習她那種把規則長在動作上的潔癖，而不是只停留在優雅的論證。
